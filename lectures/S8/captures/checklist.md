# 자가 점검 체크리스트

학습 종료 시점에 작업자가 본 학습을 충분히 했는지 확인한다.

---

## 영역 1: 이론 이해 점검

### 풀스택과 신뢰 경계

- [ ] FE와 BE의 역할 차이를 설명할 수 있는가
- [ ] 신뢰 경계(Trust Boundary)의 의미를 안다
- [ ] 비밀이 BE에만 있어야 하는 이유를 풀이할 수 있는가

### 최소 개발 지식 (이번 단위 핵심)

- [ ] HTTP 요청·응답이 무엇인지 설명할 수 있는가
- [ ] 도메인과 포트의 차이를 안다
- [ ] 환경 변수가 어떻게 코드에 주입되는지 안다 (process.env)
- [ ] 빌드와 배포의 차이를 구분한다
- [ ] API 엔드포인트가 무엇인지 안다
- [ ] 헬스체크(/health)의 목적을 안다
- [ ] 브라우저 개발자 도구(F12)의 Console·Network 탭 용도를 안다
- [ ] PORT 환경 변수가 왜 필요한지 설명할 수 있는가 (Railway 호환)

### 플랫폼과 환경 변수

- [ ] Vercel과 Railway의 역할 분담을 안다
- [ ] 환경 변수 3종류(BE 비밀 / FE 공개 / 로컬용)를 구분한다
- [ ] NEXT_PUBLIC_ 접두사의 의미와 위험을 안다

### CORS의 기획 관점

- [ ] CORS가 왜 존재하는지(보안 기획) 설명할 수 있는가
- [ ] 화이트리스트 정책 vs 모든 도메인 허용의 트레이드오프를 안다
- [ ] 첫 만남이 통과 의례인 이유를 인식한다
- [ ] 화이트리스트로 결정한 이유를 본인 말로 설명할 수 있는가

### 분석 도구 3종의 기획 가치

- [ ] Clarity가 답하는 질문을 안다 ("어디서 막히는가")
- [ ] Sentry가 답하는 질문을 안다 ("무슨 에러 있는가")
- [ ] 이벤트 추적이 답하는 질문을 안다 ("가설 통과하는가")
- [ ] 한 도구로 모든 것을 해결할 수 없는 이유를 설명할 수 있는가
- [ ] 사용자 들어오기 전 셋업의 *시점성*을 인식한다
- [ ] 세 도구가 함께 만드는 의사결정 흐름을 그릴 수 있는가

## 영역 2: 실습 산출물 점검

### 환경과 리포 구조 (Step 0)

- [ ] planning_project 폴더에서 작업 중인가
- [ ] BE 코드(server/)가 있는가
- [ ] 리포 구조가 결정됐는가 (단일 리포 권장)
- [ ] BE 코드가 `process.env.PORT` 사용하는가
- [ ] .gitignore에 .env*가 명시됐는가

### BE 배포 - Railway 8단계 (Step 1)

- [ ] Railway 가입과 GitHub 리포 연결 완료
- [ ] 새 프로젝트 생성과 자동 빌드 시작
- [ ] Root Directory가 server로 설정됐는가
- [ ] Build/Start 명령이 자동 감지됐는가
- [ ] OPENAI_API_KEY가 Variables에 등록됐는가
- [ ] Generate Domain으로 BE URL 발급됐는가
- [ ] 헬스체크 응답이 정상인가
- [ ] (실패 시) Build Logs 확인하고 자율 디버깅 적용했는가
- [ ] BE URL을 메모했는가

### FE 배포 - Vercel 5단계 (Step 2)

- [ ] Vercel 가입과 GitHub 리포 연결 완료
- [ ] Next.js Framework Preset이 자동 감지됐는가
- [ ] NEXT_PUBLIC_API_URL이 Railway URL로 등록됐는가
- [ ] 빌드 성공과 FE URL 발급
- [ ] 화면이 뜨는가 (CORS 에러는 다음 Step)

### CORS 해결 (Step 3)

- [ ] F12 Console에서 CORS 에러 풀 메시지 복사했는가
- [ ] 자율 디버깅 3원칙 명령을 사용했는가
- [ ] git-committer 자동 커밋으로 BE 코드 수정 push됐는가
- [ ] Railway 자동 재배포 완료됐는가
- [ ] CORS 에러가 사라졌는가
- [ ] 화이트리스트 정책으로 설정됐는가 (와일드카드 X)
- [ ] 시드 6번 시나리오가 공개 URL에서 동작하는가

### 분석 도구 3종 셋업 (Step 4)

- [ ] Clarity 추적 코드가 layout.tsx에 삽입됐는가
- [ ] Sentry SDK가 FE와 BE 모두에 초기화됐는가 (DSN 각각)
- [ ] 이벤트 추적 코드 3개가 적절한 위치에 있는가
- [ ] Clarity 대시보드에 본인 세션 1개가 들어왔는가
- [ ] 이벤트 3개가 Clarity Events 탭에 기록됐는가
- [ ] Sentry 테스트 에러가 도착하는가

### 토큰 비용

- [ ] /cost 비교 결과를 메모했는가
