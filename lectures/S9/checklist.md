# 자가 점검 체크리스트

학습 종료 시점에 작업자가 본 학습을 충분히 했는지 확인한다. 본 단계는 본 학습의 마지막이므로 *학습 전체의 종합 점검*도 함께 진행된다.

---

## 영역 1: 이론 이해 점검

### 노출의 기획적 의미

- [ ] 검증된 MVP와 시장이 원하는 것의 차이를 설명할 수 있는가
- [ ] 노출이 *작업자의 모름을 발견하는 단계*임을 인식하는가
- [ ] 자료 2의 두 축 안전망이 본 단계에서 어떻게 재활용되는지 안다
- [ ] 응답 0건이어도 본 단계가 진행 가능한 이유를 설명할 수 있는가
- [ ] 자료 2 콜드 메일과 본 단계 재피드백 메일의 톤 차이를 안다

### 세 축 데이터 해석

- [ ] 1명의 행동이 신호가 아닌 이유를 설명할 수 있는가
- [ ] 30% 기준 또는 3-5건 기준의 의미를 안다
- [ ] 네 종류 데이터(응답·Clarity·Sentry·이벤트 추적)가 각각 다른 질문에 답한다는 것을 안다
- [ ] 응답의 깊이와 편향의 트레이드오프를 안다
- [ ] Clarity가 *왜 그랬는지*를 모른다는 한계를 안다
- [ ] Sentry가 사용자 신뢰 침식의 안전망인 이유를 안다
- [ ] 이벤트 추적이 PRD 가설 통과율을 측정하는 방식을 안다
- [ ] NotebookLM 재오픈으로 교차 분석하는 가치를 안다

### 살아있는 페르소나로의 진화

- [ ] 페르소나 3단계 진화(가설 → 검증된 → 살아있는)를 외울 수 있는가
- [ ] 본 단계가 두 번째에서 세 번째로 가는 다리임을 인식하는가
- [ ] 페르소나 갱신의 두 종류 변화(추가·제거)를 안다
- [ ] *살아있는 상태*가 계속 갱신될 수 있는 상태임을 안다
- [ ] 페르소나 갱신이 PRD 갱신을 동반하는 이유를 안다

### 다음 사이클 결정

- [ ] 학습 종료와 빌드 종료의 차이를 인식하는가
- [ ] Pivot · Persevere · Kill 세 갈래의 의미를 구분한다
- [ ] 각 결정의 데이터 신호를 안다
- [ ] Kill 결정의 가치를 안다 (빠른 실패가 5단계 사슬을 한 번 더 도는 것)
- [ ] 매몰비용의 함정을 인식한다 (21시간 들였으니 Persevere)
- [ ] 학습 종착점이 *다음 결정 1개*임을 안다

## 영역 2: 실습 산출물 점검

### 환경과 산출물 (Step 0)

- [ ] planning_project 폴더에서 작업 중인가
- [ ] 자료 8 산출물 7개가 모두 손에 있는가
  - 공개 FE URL (Vercel)
  - 공개 BE URL (Railway)
  - Microsoft Clarity (본인 세션 1건+)
  - Sentry SDK (FE/BE 초기화)
  - 이벤트 추적 코드 3개
  - 재피드백 메일 카피 (자료 8 과제)
  - 컨택 리스트 10명+ (자료 1·2 누적)
- [ ] NotebookLM 노트북(자료 3)에 접근 가능한가
- [ ] /cost 베이스라인을 메모했는가

### 노출 발송 (Step 1)

- [ ] 발송 대상 10명 이상을 결정했는가
- [ ] 우선순위 (자료 2 인터뷰 응답자 → 자료 2 미응답자 → 자료 1 신규)를 따랐는가
- [ ] 재피드백 메일 카피의 4개 점검 항목이 통과했는가
  - 배포 URL 정확
  - 사용 시간 안내 명확
  - 응답 질문 3개 포함
  - 본인 톤
- [ ] 메일을 10명 이상에게 발송했는가
- [ ] 발송 시각이 응답률 좋은 시간대인가 (평일 9-11시 또는 19-21시)
- [ ] 발송 메모를 작성했는가

### 응답 대기 운영 (Step 2)

- [ ] 새 커뮤니티 1-2곳을 추가 스크래핑했는가
- [ ] 스크래핑 데이터 30건 이상을 수집했는가
- [ ] Clarity 대시보드를 모니터링했는가
- [ ] 응답이 도착했다면 24시간 안에 짧은 감사 답장을 보냈는가
- [ ] 응답을 즉시 분석하지 않고 Step 3-4에서 처리하기로 했는가

### 분석 도구 해석 (Step 3)

- [ ] Clarity 세션 3-5건 이상을 영상으로 봤는가
- [ ] Clarity 히트맵에서 보이지 않는 영역을 확인했는가
- [ ] Sentry 에러 패턴 1-3개를 메모했는가
- [ ] 이벤트 추적 전환율 3개를 계산했는가 (M/N, K/M, K/N)
- [ ] PRD 가설 통과 여부를 판단했는가
- [ ] 분석 메모를 양식대로 작성했는가
- [ ] 신호와 잡음을 30% 기준 또는 3-5건 기준으로 구분했는가

### NotebookLM 종합 분석 (Step 4)

- [ ] 자료 3 노트북에 응답·분석 메모·새 스크래핑을 업로드했는가
- [ ] 교차 분석 질문 4개에 NotebookLM이 답했는가
- [ ] 인용 1-2개를 클릭해 원문을 확인했는가
- [ ] 거짓 인용이 있었다면 메모했는가
- [ ] 종합 분석 메모를 양식대로 작성했는가
- [ ] 페인포인트를 세 카테고리(검증된/검증 실패/새로 발견)로 분류했는가
- [ ] PRD 가설 통과 여부를 데이터 근거와 함께 정리했는가

### 페르소나·PRD 갱신 (Step 5)

- [ ] docs/persona.md를 30% 기준으로 갱신했는가
- [ ] 추가된 특성에 데이터 근거가 있는가
- [ ] 제거된 특성이 정말 데이터에서 안 보였는가
- [ ] 페르소나 핵심 윤곽 변화가 크면 Pivot 신호로 메모했는가
- [ ] docs/prd.md의 5요소를 검토하고 갱신했는가
- [ ] 자동 커밋(git-committer)이 일어났는가
- [ ] 커밋 메시지에 갱신의 데이터 근거가 명시됐는가

### 다음 사이클 결정과 회고 (Step 6)

- [ ] AI에게 3 갈래 결정 분석을 요청했는가
- [ ] AI 추천을 그대로 받지 않고 본인 판단으로 결정했는가
- [ ] Pivot · Persevere · Kill 중 결정 1개를 내렸는가
- [ ] 결정 근거가 데이터 3개 이상으로 명시됐는가
- [ ] 1주 안 행동 1개가 구체적인가 (추상적 X)
- [ ] 1개월 안 행동 1개가 정해졌는가
- [ ] 학습 회고 3개 질문에 모두 답했는가
- [ ] 회고 답이 좋은 답(구체적)인가, 나쁜 답(모호)인가 점검했는가
- [ ] /cost 누적을 메모했는가

### 토큰 비용

- [ ] /cost 베이스라인과 종료 시점을 비교했는가
- [ ] 21시간 학습의 누적 토큰을 메모했는가
- [ ] 다음 사이클 비용 추정의 기준으로 남겼는가

## 영역 3: 학습 종착점 점검

본 단계가 본 학습의 마지막이므로 *결정을 손에 쥐고 끝나는 것*이 학습 종착점이다.

- [ ] 살아있는 페르소나로 갱신된 docs/persona.md를 손에 쥐었는가
- [ ] 갱신된 docs/prd.md를 손에 쥐었는가
- [ ] 다음 사이클 결정 메모(docs/next-cycle.md)를 손에 쥐었는가
- [ ] 1주 안 행동 1개가 명확한가
- [ ] 5단계 사슬의 약한 고리를 인식하는가
- [ ] 본 학습 후 본인 사이클의 첫 걸음이 명확한가

다섯 항목 모두 통과되면 학습 종료. 한 항목이라도 통과 안 되면 본 단계에서 해당 항목을 다시 채우고 끝낸다.

---

## 영역 4: 기획 관점 점검

- [ ] 검증된 MVP가 시장이 원하는 것과 다를 수 있음을 인식하는가
- [ ] 데이터의 30% 기준이 본인 시드에 어떻게 적용되는지 그릴 수 있는가
- [ ] 페르소나 갱신이 PRD 5요소 갱신을 동반하는 흐름을 안다
- [ ] AI 추천 결정과 본인 결정의 차이를 인식하는가 (검증 우선주의)
- [ ] Kill 결정이 실패가 아니라 빠른 학습임을 본인 말로 설명할 수 있는가

## 영역 5: 학습 전체 종합 점검

본 학습의 마지막 단계이므로 *학습 21시간 전체*를 회고하는 영역이다.

### 5단계 사슬 회고

- [ ] 문제 단계(자료 1)의 5 Whys 적용 깊이를 평가했는가
- [ ] 페르소나 단계(자료 1·2·3·본 단계)의 진화 과정을 인식하는가
- [ ] 가설 단계(자료 1)의 검증 가능 형식을 본인이 적용했는가
- [ ] 검증 단계(자료 2·본 단계)의 두 축 운영을 본인이 수행했는가
- [ ] 정제 단계(자료 3·5·6·7·본 단계)의 누적 갱신을 인식하는가
- [ ] 본 학습에서 가장 약했던 단계를 명시했는가

### AI 도구 활용 회고

- [ ] 메타 프롬프팅 (자료 2)을 본인이 적용했는가
- [ ] NotebookLM 출처 검증 (자료 3)을 본인이 적용했는가
- [ ] Manyfast PRD 작성 (자료 3)을 본인이 수행했는가
- [ ] CLAUDE.md 4영역 (자료 4)을 본인이 작성했는가
- [ ] 위임 3원칙 (자료 5)을 본인이 빌드 명령에 적용했는가
- [ ] sub-agent 6원칙 (자료 6)을 본인이 적용했는가
- [ ] hooks PostToolUse/Stop (자료 6)을 본인이 셋업했는가
- [ ] 자율 디버깅 3원칙 (자료 7)을 본인이 적용했는가
- [ ] scenario-verifier (자료 7)을 본인이 활용했는가
- [ ] Vercel/Railway 배포 (자료 8)을 본인이 수행했는가
- [ ] 분석 도구 3종 (자료 8)을 본인이 셋업했는가
- [ ] 가장 가치 있었던 도구를 명시했는가
- [ ] 가장 어려웠던 도구를 명시했는가

### 검증 우선주의의 일관 적용 회고

- [ ] 자료 1의 출처 검증 (3가지 거짓 패턴)을 본인이 적용했는가
- [ ] 자료 3의 NotebookLM 인용 클릭을 본인이 적용했는가
- [ ] 자료 6의 sub-agent 보고서 검증을 본인이 적용했는가
- [ ] 자료 7의 자율 디버깅 결과 검증을 본인이 적용했는가
- [ ] 본 단계의 다음 사이클 결정 검증을 본인이 적용했는가
- [ ] 검증 우선주의가 21시간 학습 전체에 일관 적용됨을 인식하는가

## 영역 6: 본 학습 후 자가 운영 점검

본 학습 종료 후 본인 사이클을 다시 돌릴 수 있는지 점검.

- [ ] 자료 1-9를 자가 학습 자원으로 활용할 수 있는가
- [ ] 두 번째 사이클부터 시간 단축이 가능함을 인식하는가
- [ ] 메타 프롬프팅·위임 3원칙·검증 우선주의가 본 학습 후 모든 프로젝트에 재사용됨을 안다
- [ ] 본 학습에서 만난 다른 학생과의 컨택 유지 의사가 있는가 (선택)
- [ ] 다음 사이클에서 막혔을 때 어디를 다시 보면 되는지 안다

## 영역 7: 본 학습의 가치 점검

본 학습 21시간이 *본인에게* 가치 있었는지 본인 말로 점검.

- [ ] 본 학습에서 만난 가장 큰 깨달음 1개를 본인 말로 정리했는가
- [ ] 본 학습이 *시작이지 끝이 아님*을 인식하는가
- [ ] 본인 시드의 6개월 후 모습을 그릴 수 있는가
- [ ] 본 학습의 가치를 다른 사람에게 한 줄로 전달할 수 있는가

## 학습 종료 선언

다음 5가지가 모두 손에 있으면 학습 종료를 선언한다.

```
✅ 살아있는 페르소나로 갱신된 docs/persona.md
✅ 갱신된 docs/prd.md
✅ 다음 사이클 결정 1개 (Pivot/Persevere/Kill)
✅ 1주 안 행동 1개 (구체적)
✅ 5단계 사슬의 약한 고리 인식
```

한 항목이라도 비어 있으면 본 단계의 해당 Step으로 돌아가 보강 후 학습 종료.
