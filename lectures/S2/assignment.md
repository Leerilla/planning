# 과제: 능동·수동 두 축 검증 본격 가동

## 목표

다음 학습 단계 시작 전까지 능동 검증과 수동 검증 두 축을 본격 가동해 데이터 자산을 누적한다. 능동 카피 발송과 수동 데이터 수집이 완료된 상태로 다음 단계에 진입한다.

---

## 산출물

다음을 다음 단계 시작 전까지 완성한다.

- **능동 검증 발송 완료**: 카피 발송 10명 이상 (이전 단계 컨택 리스트 활용)
- **수동 검증 데이터 누적**: 페르소나 커뮤니티에서 글이나 리뷰 50건 이상 수집
- (선택) 발송 카피와 스크래핑 데이터의 1차 훑어보기 메모

---

## 최소 인정 범위

다음을 충족하면 본 과제를 인정한다.

- 카피 발송 5명 이상
- 수집 데이터 50건 이상
- 발송 채널과 수집 커뮤니티가 페르소나에 부합

---

## 권장 범위

다음까지 하면 다음 단계 분석이 더 자연스럽다.

- 카피 발송 20명 이상
- 수집 데이터 200건 이상
- 데이터 1차 훑어보기 메모(공통 단어, 페인포인트 신호)
- 응답 도착 시 즉시 알림이 오도록 설정

---

## 자가 점검 체크리스트

작업 종료 후, 다음 단계 시작 전 작업자가 점검한다.

- [ ] 발송한 메일/DM 카피를 다시 읽었을 때 부끄럽지 않은가
- [ ] 발송 채널이 페르소나가 실제 활동하는 곳인가
- [ ] 스크래핑 데이터가 정말 페르소나의 목소리인가
- [ ] 데이터를 한 번이라도 훑어봤는가
- [ ] 응답이 도착했을 때 알림이 오는가

---

## 막혔을 때

| 시나리오 | 대응 |
| --- | --- |
| **컨택처에 메일이 막힌다** | 채널을 변경한다. 링크드인이 막히면 네이버 카페 쪽지로, 카페가 막히면 디스콰이엇으로 |
| **스크래핑이 동작하지 않는다** | 에러 메시지를 그대로 Claude Code에 붙여넣고 자가 디버깅한다. "Playwright MCP가 X 사이트에서 멈췄다. 로그는 다음과 같다"의 형태로 |
| **응답률이 너무 낮다** | 메타 프롬프팅 가이드라인을 다시 점검한다. 첫 줄 후크가 페인포인트 키워드를 담고 있는지 확인 |
| **응답이 0건이다** | 트랙 B 안전망 가동. 수동 데이터 200건으로 다음 단계 진입 가능 |
| **페르소나가 활동하는 커뮤니티를 모른다** | ChatGPT에 "{페르소나}가 활동하는 한국 온라인 커뮤니티 리스트"를 묻고 출처 1개 검증 |

---

## 1차 훑어보기 메모 양식 (선택)

데이터를 모은 뒤 다음 양식으로 짧게 메모하면 다음 단계 분석이 빨라진다.

```
[페인포인트 신호 1차 메모]

- 가장 자주 등장한 키워드 3개: {예: 정리 누락, 받아쓰기, 결정 사항 추출}
- 페르소나 1차 가설과의 일치도: {일치 / 부분 일치 / 불일치}
- 가장 강한 페인포인트 1개: {핵심 페인포인트와 그 출처 글 URL}
- 다음 단계에서 더 볼 부분: {예: 액션아이템 vs 결정 사항 어느 쪽이 큰가}
```

## 마감

다음 학습 단계 시작 전.

운영 5대 원칙 4번(MVP 스코프 자율 조절)에 따라 산출물의 완성도가 100%가 아니어도 된다. 최소 인정 범위까지 도달 + 자가 점검 체크리스트 통과가 합격선이다. 발송 20명이 무리하면 5명까지 줄여도 되고, 데이터 200건이 무리하면 50건으로 시작해도 된다.
