# 과제: 1차 가설 워크시트 + 컨택 리스트 + 본인 아이디어 후보

## 목표

다음 단계 검증 시작에 필요한 입력 자산을 확보한다. 완성된 1차 가설 워크시트, 페르소나에 부합하는 컨택 리스트, 작업자가 결정한 아이디어 후보를 손에 쥔 상태로 다음 단계에 진입한다.

---

## 산출물

다음을 다음 단계 시작 전까지 완성한다.

- **완성된 기획 워크시트**: 문제 1줄 + 페르소나 5줄 + 핵심 가설 3개
- **컨택 리스트 20명**: 페르소나에 부합하는 실제 사람의 링크드인 URL, 이메일 주소, 또는 네이버 카페 ID. 클릭 가능한 형태
- **본인 아이디어 후보 3개**: 시드 그대로 1개, 시드 변형 1개, 본인 관심사 변형 1개. 또는 본인 아이디어 1개로 좁혀 와도 된다
- (선택) 1차 리서치에서 발견한 거짓 메모: 출처 검증 능력의 흔적

---

## 최소 인정 범위

다음을 충족하면 본 과제를 인정한다.

- 워크시트 완성 (문제 1줄 + 페르소나 5줄 + 가설 3개 모두 채워짐)
- 컨택 리스트 10명 이상
- 본인 아이디어 1개로 좁힘

---

## 권장 범위

다음까지 하면 다음 단계 진입이 더 자연스럽다.

- 워크시트 완성 + 컨택 리스트 20명
- 각 컨택처를 어떻게 찾았는지 한 줄 메모 (예: "링크드인 'PM' + '5-30인 스타트업' 검색 결과 상위 30명 중 응답 가능성 있어 보이는 20명")
- 출처 검증에서 발견한 거짓 1개 이상 메모
- 본인 아이디어 후보 3개 모두 적은 뒤 1개로 좁힘 (좁힌 이유 한 줄)

---

## 자가 점검 체크리스트

작업 종료 후, 다음 단계 시작 전 작업자가 점검한다.

- [ ] 문제를 한 문장으로 말할 수 있는가 (누구·상황·문제 셋 다 들어감)
- [ ] 페르소나 5줄을 짧고 구체적으로 묘사했는가 (모든 줄이 채워짐)
- [ ] 핵심 가설 3개가 검증 가능한 형식인가 ("~할 의향이 있을 것이다" 또는 "~를 더 선호할 것이다")
- [ ] 컨택 리스트의 사람들이 정말 페르소나인가 (페르소나 5줄과 대조)
- [ ] 컨택처를 보면 클릭 가능한 링크 또는 주소가 있는가 (모호한 메모 0건)
- [ ] 본인 아이디어 1개로 좁혔는가

---

## 막혔을 때

| 시나리오 | 대응 |
| --- | --- |
| **컨택처가 모이지 않는다** | ChatGPT 또는 Gemini에 "{페르소나}가 활동하는 한국 온라인 커뮤니티 리스트를 알려줘"를 묻고, 답변의 출처 1개 이상을 클릭해 직접 확인. 검증된 커뮤니티 1개에서 실제 사람의 ID 또는 링크 추출 |
| **본인 아이디어 후보가 떠오르지 않는다** | 시드 6개 중 본인 경험과 가장 가까운 1개를 베이스로, 페르소나만 본인 주변 사람으로 변형. 예: "5-30인 스타트업 PM"을 "본인이 다닌 회사의 팀장"으로 |
| **페르소나 5줄 중 검증 가능 채널이 채워지지 않는다** | 페르소나가 너무 모호한 것. 직군·환경 조건을 더 좁힌 뒤 다시 채널을 찾는다. "직장인"을 "5-30인 스타트업 PM"으로 |
| **가설 3개 중 1개 이상이 검증 불가능 형식이다** | "~쓸 만하다", "~좋다" 같은 모호 표현은 검증 불가. "~할 의향이 있을 것이다", "~를 더 선호할 것이다"로 다시 작성 |
| **AI 답변에 출처가 들어가지 않는다** | "방금 답변에서 통계 또는 인용 1개 이상에 대해 1차 출처 URL을 첨부해줘"로 다시 묻기. 그래도 들어가지 않으면 그 답변은 검증 불가능. 사용하지 않음 |

## 마감

다음 학습 단계 시작 전.

운영 5대 원칙 4번(MVP 스코프 자율 조절)에 따라, 산출물의 완성도가 100%가 아니어도 된다. 최소 인정 범위까지 도달 + 자가 점검 체크리스트 통과가 합격선이다. 컨택 리스트 20명이 무리하면 10명까지 줄여도 된다. 단, 워크시트 완성과 본인 아이디어 1개로 좁히는 것은 양보 불가이다. 이 둘이 다음 단계의 입력이다.
