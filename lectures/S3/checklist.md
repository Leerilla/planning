# 자가 점검 체크리스트

학습 종료 시점에 작업자가 본 학습을 충분히 했는지 확인한다. 한 항목이라도 미통과면 그 항목은 과제로 가져간다.

---

## 영역 1: 이론 이해 점검

- [ ] PRD가 인간과 AI 사이의 계약서인 이유를 설명할 수 있는가
- [ ] 좋은 PRD의 5요소(문제·페르소나·핵심 기능·성공 지표·제약사항)를 떠올릴 수 있는가
- [ ] NotebookLM과 Manyfast의 역할 차이를 본인 말로 말할 수 있는가
- [ ] 분석과 정제의 사고 작업 차이를 인지하고 있는가
- [ ] AI 자동 검토를 그대로 신뢰하지 않는 이유를 떠올릴 수 있는가

---

## 영역 2: 실습 산출물 점검

- [ ] NotebookLM 노트북이 생성됐고 데이터가 업로드됐는가
- [ ] 페인포인트 5개 이상이 출처 인용과 함께 추출됐는가
- [ ] 인용 1개 이상을 직접 클릭해 검증했는가
- [ ] Manyfast PRD가 5요소를 모두 갖췄는가
- [ ] 모호한 표현 1개 이상을 직접 수정했는가
- [ ] 핵심 기능이 3개 이하로 좁혀졌는가
- [ ] prd.md 파일이 작업 폴더에 있는가
- [ ] /cost 비교 결과를 메모했는가

---

## 영역 3: 과제 진입 가능성 점검

- [ ] 과제의 첫 단계(전체 데이터 업로드)를 어디서 시작할지 알고 있는가
- [ ] PRD 검토 5개 점검 항목을 외울 수 있는가
- [ ] 막혔을 때 어떤 명령 패턴을 사용할지 알고 있는가

---

## 영역 4: 다음 단계 연결 점검

- [ ] 다음 단계로 가져갈 입력 자산(prd.md, Manyfast 프로젝트, NotebookLM 노트북)을 알고 있는가
- [ ] 다음 단계가 PRD를 에이전트에게 전달하는 단계임을 알고 있는가
- [ ] Manyfast MCP 연동의 의미를 떠올릴 수 있는가
- [ ] PRD 검토 5개 점검 항목을 외울 수 있는가
- [ ] 핵심 기능 3개의 표준 구성(입력+처리+출력)을 떠올릴 수 있는가
